=== OC Lisala – Contenus du club ===
Requires at least: 6.2
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Types de contenus de l'Olympique Club de Lisala : membres de l'équipe, publicités et partenaires officiels.

== Description ==

Ajoute au menu « Gestion du site » :

* Équipe : photo, nom complet, fonction, groupe, numéro de maillot, description, statut actif / inactif, ordre.
* Publicités : image, lien, ouverture dans un nouvel onglet, statut, ordre.
* Partenaires officiels : logo, nom, site web, statut, ordre.

L'ordre se règle par glisser-déposer dans chaque liste ; un clic sur « Actif / Inactif » change le statut.
Les contenus sont enregistrés dans la base WordPress et restent disponibles si le thème change.
L'affichage est assuré par le thème « OC Lisala ».

== Installation ==

Depuis le thème OC Lisala : bouton « Installer et activer l'extension » du tableau de bord.
Ou : Extensions > Ajouter > Téléverser une extension, choisir oc-lisala-core.zip, puis Activer.
